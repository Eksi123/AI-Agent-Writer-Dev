# 文件信息查询工具

## 描述

获取文件的详细信息，包括大小、创建时间、修改时间、行数等。

## 工具列表

### file_info

- **功能**: 获取指定文件的元信息
- **参数**:
  - `file_path` (str, 必填): 文件的绝对路径或相对路径
- **返回**: 文件详细信息（路径、类型、大小、创建/修改/访问时间、行数）

## 使用示例

```python
result = file_info(file_path="output/novel/outline.md")
print(result)
# 输出: 文件信息: 路径=..., 类型=文件, 大小=1.23 KB, ...
```

## 注意事项

- 文件必须存在，否则返回错误信息
- 对于非 UTF-8 编码的文件，行数统计可能失败
