# 字数统计工具

## 描述

统计文本的字数、字符数和行数，适用于快速了解文本规模。

## 工具列表

### word_count

- **功能**: 统计文本的字数、字符数（含/不含空格）和行数
- **参数**:
  - `text` (str, 必填): 要统计的文本内容
- **返回**: 包含字符数、词数、行数的统计结果字符串

## 使用示例

```python
result = word_count(text="Hello World\n这是一段测试文本")
print(result)
# 输出: 字符数（不含空格）: 15, 字符数（含空格）: 17, 词数: 5, 行数: 2
```

## 注意事项

- 词数统计按空白字符分割
- 中文字符每个算一个字符
