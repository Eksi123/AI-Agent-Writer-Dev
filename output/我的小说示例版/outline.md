# 大纲模板

> 这是一个大纲模板文件，用于指导用户如何编写小说大纲。
> 用户在 Web 页面可以预览此模板。

---

## 大纲文件格式说明

outline.md 包含小说的所有设定信息（故事梗概、角色设定、世界观、写作要求、自定义提示词、分卷分章剧情概要），是整个小说项目的核心文件。

---

## 模板示例

```markdown
# 小说名称

- 作者：作者名
- 类型：玄幻 / 都市 / 科幻
- 状态：planning / writing / completed
- 一句话简介：...

## 1. 故事梗概
（500-1000字的故事梗概）

## 2. 主题
- 主题1
- 主题2

## 3. 角色设定

### 3.1 主角：角色名
- 年龄：25
- 性别：男/女
- 性格：性格特点描述
- 背景：背景故事
- 动机：动机1、动机2
- 成长弧线：角色成长弧线描述

#### 关系
- 与 角色B：朋友关系，描述...
- 与 角色C：敌对关系，描述...

### 3.2 配角：角色B
...

## 4. 世界观设定

### 4.1 世界背景
世界背景描述...

### 4.2 时代背景
...

### 4.3 力量体系
...

### 4.4 世界规则
- 规则1
- 规则2

## 5. 写作要求

### 5.1 风格
轻松幽默 / 严肃沉重

### 5.2 基调
积极向上 / 黑暗压抑

### 5.3 视角
第一人称 / 第三人称

### 5.4 目标字数
10万 - 30万字

### 5.5 特殊约束
- 约束1
- 约束2

## 6. 自定义提示词（可选）

如果提供此部分，将覆盖对应 Agent 的默认系统提示词。

### 6.1 写作 Agent
你是一个专业的小说写手...

### 6.2 大纲润色 Agent
你是一个大纲优化专家...

### 6.3 审查 Agent
你是一个严格的小说审查员...

## 7. 第一卷：卷标题

本卷概要（200-500字）

### 7.1 第1章：章节标题
- 章节概要（100-300字）
- 要点：要点1、要点2
- 出场角色：角色1、角色2
- 目标字数：5000

### 7.2 第2章：章节标题
- ...

## 8. 第二卷：卷标题
...
```

---

## 章节文件命名规范

- 格式：`vol{卷序号}_ch{章节序号}_{章节名}.md`
- 示例：
  - `vol1_ch01_初入江湖.md`
  - `vol1_ch02_神秘老者.md`
  - `vol2_ch15_最终决战.md`
- 章节内容采用 Markdown 格式，包含标题、正文、对话等

---

## 审查机制

- 审查结果不生成独立文件
- 审查发现问题时，Agent 直接通过对话询问用户是否修改
- 用户确认后 Agent 执行修改，无需人工查看审查报告

---

## 小说导出

- 导出时由用户自选本地目录保存
- 支持导出为 TXT / Markdown 格式
- 导出不存放在 output 目录下
