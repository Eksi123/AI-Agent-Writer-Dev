# 蟠桃会上忆前尘，倩影佳人入梦频

蟠桃盛会，瑶池之上，仙乐悠扬，祥云缭绕。

各路仙家觥筹交错，笑语喧哗。铁拐李饮了一口琼浆，咂咂嘴，对身旁的吕洞宾道：“老吕，你瞧瞧这蟠桃，比四百年前那回，可大了不少。”

吕洞宾摇着拂尘，笑道：“李兄，莫非是你的拐杖又沉了几分？这才觉得蟠桃小了？”

众人哄笑。何仙姑手持荷花，轻轻一抖，几粒晶莹的露珠便如珍珠般滚落，在半空中化作点点星辉。“四百年前，我们八仙齐聚，为的是渡海采药，却未曾想到，那一场东海风波，竟成了韩师兄心中一道永远的劫。”她目光温婉，望向席末的韩湘子。

韩湘子正举杯浅酌，闻言并未抬头，只是唇角微不可察地牵动了一下。

张果老倒骑在毛驴背上，笑呵呵地道：“可不是么？当年那场大战，打得天昏地暗，连东海龙王敖广都气得胡子直翘。可谁又能想到，最让韩师兄心痛的，不是那惊天动地的斗法，而是……”他顿了顿，声音低沉下来，“而是那条碧翠青龙，以命相护之后，消散于天地间的最后一笑。”

席间一时静默。连那喧闹的仙乐，似乎也低沉了几分。

汉钟离拍了拍圆滚滚的肚子，叹道：“韩兄弟，四百年了，你日日抚箫，夜夜思量，这心境上的裂痕，非但未愈，反而愈发深了。你可知为何？”

韩湘子终于放下酒杯，抬眸看向这位豪迈的兄长，眼中一片平静：“钟离兄请讲。”

“非修为不足，乃心境有缺。”汉钟离的声音洪亮而恳切，“你已至天仙极致，距离金仙，只差那一线之隔。可这线，却如天堑。你的心里，装着一个‘艳’字，一个‘彩’字，这两个字，便是你道心上最大的破绽。”

蓝采和提着花篮，从旁边凑过来，篮中百花争艳，香气扑鼻。“韩哥哥，你总说‘情之一字，最是能伤人’，可依我看，情之一字，亦是最能渡人的舟楫。你若一味强压，它便如烈火，焚尽你所有道基；你若顺流而下，它或能载你，抵达彼岸。”

曹国舅手执玉板，轻轻敲击，发出清越之声：“韩兄，我等皆知，你天资卓绝，悟性无双。若论法力，你早已不输我等。可这证道金仙，修的并非法力，而是心境。心若圆满，万劫不灭；心若有缺，纵有通天彻地之能，亦不过是一介真仙罢了。”

韩湘子沉默良久，目光扫过一张张熟悉而关切的脸庞。四百年来，他们从未劝他忘却，只是默默陪伴，看着他一次次冲击境界，又一次次败退归来。

就在此时，吕洞宾放下拂尘，神色变得郑重起来。“韩兄，我有一言，不知当讲不当讲。”

“吕兄请讲。”韩湘子道。

吕洞宾环顾四周，见众仙皆凝神倾听，方才缓缓开口：“艳彩公主，已历七世轮回。第八世，转生在西蜀之地。你何不以化身下凡，与她结一世之缘？了却这段尘缘，方能心无挂碍，突破金仙。”

此言一出，满座皆惊。

铁拐李手中的龙头拐杖一顿，目光如电：“吕兄，此言非同小可。化身下凡，历红尘劫，风险极大。若化身再陷情障，本尊道基同样受损，恐有跌落之危！”

吕洞宾点头，神色凝重：“正是如此。玉帝当年降罚，将艳彩形神削去、融入玉箫，其元神其实并未彻底消散，而是入了轮回。这既是生机，亦是险境。化身历劫，若不能勘破，反会将本尊拖入万劫不复之地。”

韩湘子的心，仿佛被一只无形的手攥紧。他低头看着自己放在膝上的双手——这双手，曾握过紫竹洞箫，也曾拂过艳彩的发梢；这双手，曾为她挡过刀剑，也曾亲手撕碎过她贴在墙上的告示。

“若她已转世……”他喃喃道，声音轻得如同叹息，“那我，是否还能认出她？”

“认得出，也认不出。”吕洞宾意味深长地一笑，“你认得出她灵魂深处的那一抹光，却认不出她今生的眉眼与身姿。这，便是红尘的妙处。”

何仙姑接过话头，柔声道：“你的情太深，强压不如疏导。与其在紫霄仙境中枯坐四百年，不如入红尘走一遭。爱过，恨过，错过，再寻回……待你真正明白‘情’为何物，那一线之隔，自会消弭于无形。”

韩湘子闭上眼，脑海中浮现出昨夜瑶池中那朵凋零的莲花，以及光影中那抹温柔的笑意。

他再次睁开眼时，眸中已无迷茫，只有一片澄澈的坚定。

“多谢诸位兄长指点。”他起身，向八仙深深一揖，动作庄重而谦逊，“韩湘子，愿以化身下凡，寻她一世。”

话音落下，整个瑶池仿佛都安静了一瞬。

就在这时，一阵清风拂过，吹散了韩湘子额前的一缕碎发。他抬起头，望向远方。在那里，云海翻涌，隐约可见一片苍翠的山峦轮廓，山势雄奇，云雾缭绕，仿佛一幅水墨丹青。

“西蜀……”他低声念道，仿佛在确认一个即将启程的目的地。

宴席继续，仙乐重新响起，比先前更加欢快。八仙纷纷举杯，为韩湘子送行。

唯有韩湘子，独自一人，悄然离席，走向瑶池深处。

月华如练，洒在他清瘦的背影上。他取出袖中那支珍藏了四百年的碧翠短箫，指尖轻轻拂过那温润的箫管。箫身在月光下泛着幽幽的碧光，仿佛一颗亘古不变的星辰。

“艳彩，”他对着浩渺的星空低语，“这一次，我不再是那个懵懂无知的少年，也不再是那个固执己见的仙人。这一次，我以凡人之躯，赴你之约。”

他将短箫贴在心口，仿佛能感受到那跨越四百年的脉搏，正与自己的心跳，渐渐合拍。

远处，八仙的欢笑声隐隐传来，而韩湘子的世界里，只剩下这箫声与心跳交织的韵律。

他不再是一个等待救赎的仙人，而是一个奔赴约定的旅人。
